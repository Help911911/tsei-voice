# tsei-voice

태성환경연구소 영업관리 웹앱(구글 앱스 스크립트)용 **🎤 음성 입력 화면**.

구글 웹앱 화면 안에서는 브라우저가 마이크를 막기 때문에, 웹앱의 🎤 버튼이 이 화면을 새 창으로 엽니다.
말한 내용은 브라우저 음성 인식(Web Speech API, ko-KR)으로 글자가 되고, 「입력칸에 넣기」를 누르면 웹앱의 입력칸으로 돌아갑니다.

- 주소: https://help911911.github.io/tsei-voice/
- 서버·저장 없음 (정적 HTML 1개). 결과는 이 화면을 연 영업관리 웹앱(`*-script.googleusercontent.com`)에만 `postMessage`로 전달
- 지원: 안드로이드 크롬, 아이폰 사파리, PC 크롬·엣지 (마이크 필요)
